# VR Field 1.3.0

VR Field остаётся 2D-пространством, но трекинг стал отдельными слоями: камера → скелет → глаза → голова → жестовое движение. Персонаж получает псевдо-3D поворот без полноценной 3D-сцены.

## Что изменилось

- Живое изображение камеры выводится через отдельный `cameraPreview` canvas. Медиа-поток сначала подключается к `<video>`, после первого кадра рисуется в canvas. Загрузка MediaPipe больше не блокирует изображение.
- В калибровке есть **«Пропустить калибровку»**. Это обход проверки, а не отключение самой камеры.
- Калибровка разбита на 7 шагов: камера, тело, левая рука, правая рука, глаза близко, глаза далеко, голова.
- Глаза используют отдельный Face Landmarker и отображаются зелёными точками во время проверки. Близкая/дальняя калибровка хранит базовую точку взгляда и масштаб.
- Голова получает отдельный yaw/pitch-трек.
- В настройках можно отдельно включать/выключать тело, глаза, голову, жестовое движение и прыжок, а также менять чувствительность и плавность.
- Если игрок исчезает из кадра более чем примерно на секунду, персонаж плавно возвращается в спокойную позу; после возвращения он плавно подхватывает новую позу.
- Движение: вытянутая вбок рука, удерживаемая около секунды, добавляет движение в ту сторону. Реальное смещение человека в кадре тоже используется как X-позиция.
- Прыжок определяется по резкому подъёму центра тела относительно базовой точки.
- Персонаж теперь рисуется в нескольких плоскостях: передняя, 3/4 и боковая. Ширина головы/тела, скрытие дальней руки и положение глаз меняются от yaw — это псевдо-3D в 2D.
- Добавлена локальная галерея новых вариаций персонажа и референс пользователя.

## Камера

`openCamera()` не вызывает `video.load()` после `srcObject`, ждёт первый живой кадр и только затем применяет необязательный zoom с коротким таймаутом. Дополнительные настройки камеры никогда не являются условием показа превью.

## Внешние модели

MediaPipe Tasks Vision и модели по-прежнему загружаются с CDN/Google Storage. Среда разработки в этой сборке не смогла скачать npm-пакет из-за отсутствия DNS, поэтому vendor-бандл внутри архива не обещается как офлайн-ресурс. При ошибке модели сайт не скрывает камеру и предлагает пропустить калибровку.

## Тесты

`npm test` запускает чистые unit/smoke тесты. В этой среде полный smoke-тест с Express/WebSocket не был выполнен без установки зависимостей; синтаксис всех JS-файлов и чистая логика проверены локально.

## Запуск

```bash
npm install
npm start
```

На Render используй HTTPS, чтобы браузер мог выдавать разрешение на камеру.
