# VR Field — 1.0.0

Готовая первая версия сайта без видимого 3D: строгий 2D-интерфейс, 2D-мир, персонажи из шариков/точек, телефонный трекинг, VR/WebXR-проверка, скины и real-time backend.

## Сценарий

1. Открываешь сайт.
2. Вводишь имя и выбираешь готовый скин или создаёшь свой.
3. Можно ввести код уже существующей комнаты или оставить поле пустым — тогда создастся новая.
4. Выбираешь `Телефон` или `VR`.
5. Телефон проходит калибровку: камера → видимость тела → левая рука → правая рука.
6. Сайт показывает RTT/задержку до backend и советует улучшить освещение, если точек тела мало.
7. После проверки появляется 2D-мир. Влево/вправо ходим стрелками/A/D, руки и голова следуют входным данным.
8. Для телефона в комнате есть QR-код. Телефон подключается по ссылке и отправляет только числовые данные позы.

## Скины

Есть шесть готовых вариантов. В редакторе `Создать свой скин` можно рисовать мышью или пальцем, затем переключиться в `Кости` и вручную расставить точки головы, плеч, рук, бёдер и стоп. Сохраняются цветовая схема, рисунок и координаты рига.

## Backend

Сервер: Node.js + Express + WebSocket (`ws`).

Он обслуживает:

- комнаты и коды;
- подключение хоста и телефона;
- real-time обмен motion/pose;
- измерение ответа backend через ping/pong;
- очистку зависших подключений.

Render Web Services поддерживают входящие WebSocket-соединения. Для публичного Render соединение должно использовать `wss://`. См. официальную документацию Render: https://render.com/docs/websocket

## GitHub → Render

1. Создай/открой репозиторий GitHub.
2. Залей содержимое этой папки в корень репозитория.
3. В Render выбери **Web Service** и подключи этот репозиторий.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. После деплоя используй HTTPS-адрес Render.

`render.yaml` уже содержит базовую конфигурацию сервиса.

## Локальный запуск

Для полноценной версии нужен Node.js backend:

```bash
npm install
npm start
```

После этого открыть `http://localhost:3000`.

Обычный VS Code Live Server теперь подходит только для просмотра статической части. Он не запускает наш backend/WebSocket, поэтому комнаты и связь игроков через него работать не будут. Для полного теста используй `npm start` или Render.

## Камера и VR

Камера через `getUserMedia()` и WebXR требуют secure context. HTTPS на Render подходит для этих API. WebXR при этом имеет ограниченную поддержку браузерами и зависит от конкретного шлема/браузера.

Документация MDN:
- getUserMedia: https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia
- WebXR security: https://developer.mozilla.org/en-US/docs/Web/API/WebXR_Device_API/Permissions_and_security
