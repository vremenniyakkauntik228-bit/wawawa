# API

Base path: `/api/v1`

## Authentication

Set `ENGINE_API_KEY` in the server environment to require authentication. Clients can send either:

```http
X-API-Key: <key>
```

or:

```http
Authorization: Bearer <key>
```

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/health/live` | process liveness |
| GET | `/health/ready` | readiness + supported formats |
| GET | `/formats` | adapter capabilities |
| GET | `/manifest` | engine identity and capabilities |
| POST | `/files` | upload file |
| DELETE | `/files/{file_id}` | delete source file |
| POST | `/jobs` | create async job |
| GET | `/jobs/{job_id}` | status/progress/result metadata |
| POST | `/jobs/{job_id}/cancel` | cancel a queued/running job |
| POST | `/jobs/{job_id}/retry` | retry a failed/timed-out/cancelled job |
| GET | `/jobs/{job_id}/result` | result descriptor |
| GET | `/jobs/{job_id}/download` | result artifact download |
| GET | `/jobs/{job_id}/events` | event history |

## Create job example

```json
{
  "file_id": "9d1...",
  "operation": "convert",
  "output_format": "pdf",
  "options": {
    "title": "Converted document",
    "correct": true
  },
  "webhook_url": "https://example.com/hooks/engine"
}
```

Supported operations: `analyze`, `validate`, `extract_text`, `correct_text`, `convert`.

`output_format` is required for `convert`, optional for the other text-producing operations.

## Terminal states

`completed`, `failed`, `timed_out`, `cancelled`.

## Error shape

```json
{
  "error": {
    "code": "unsupported_format",
    "message": "Unsupported document format: exe",
    "details": {"format": "exe"},
    "request_id": "..."
  }
}
```

Interactive OpenAPI schema is generated by FastAPI at `/openapi.json`.

## Idempotency

`POST /api/v1/jobs` accepts an optional `Idempotency-Key` header (1-255 characters). Reusing the same key with the same request returns the original job instead of creating a duplicate. Reusing the key with a different request returns `409 idempotency_conflict`.

## Cancellation and retry

- `POST /api/v1/jobs/{id}/cancel` cancels queued or running jobs. Running workers are terminated as a process group where supported.
- `POST /api/v1/jobs/{id}/retry` resets a failed, timed-out or cancelled job and queues it again.
